# 🐍 Estudos em Python

Bem-vindo ao meu repositório de estudos em **Python**!

Este repositório foi criado para registrar minha evolução no aprendizado de programação, reunindo exercícios, desafios e práticas desenvolvidos durante o curso de Python do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

## 📚 Sobre o projeto

O objetivo deste repositório é documentar minha jornada de aprendizado, desenvolver o raciocínio lógico e aprimorar minhas habilidades de programação.

Aqui você encontrará:

- 💻 Exercícios práticos em Python.
- 🧠 Desafios de lógica de programação.
- 📈 Minha evolução ao longo do curso.
- 📝 Códigos desenvolvidos durante os estudos.

## 📂 Organização do repositório

Os exercícios são organizados em pastas conforme avanço no conteúdo do curso.

- **M1/** — Exercícios e desafios do Mundo 1: Fundamentos de Python.
- **README.md** — Documentação e apresentação do repositório.

A organização será atualizada conforme o progresso dos estudos.

## 🎯 Objetivos de aprendizado

- Compreender os fundamentos da linguagem Python.
- Desenvolver o pensamento lógico e a resolução de problemas.
- Praticar estruturas condicionais, repetições e funções.
- Aprender a escrever códigos claros e organizados.
- Construir uma base sólida para projetos futuros.
